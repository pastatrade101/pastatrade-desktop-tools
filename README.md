# Pastatrade Music desktop tools

Helper programs the Pastatrade Music apps for Mac and Windows download the
first time someone saves a song: yt-dlp and FFmpeg, fetched from their
publishers by the `Desktop tools` workflow, checked against the publishers'
own SHA-256 fingerprints and attached to the `desktop-tools-1` release. The app
checks each file again against fingerprints pinned in its code.

- yt-dlp (Unlicense): https://github.com/yt-dlp/yt-dlp
- FFmpeg (GPL): Mac builds by Martin Riedl (https://ffmpeg.martin-riedl.de),
  Windows build by gyan.dev (https://www.gyan.dev/ffmpeg/builds/). Source:
  https://ffmpeg.org/download.html

Nothing else lives here.
